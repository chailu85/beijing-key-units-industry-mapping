# 421 重点行业分类统计

按北京市国标行业分类（GB/T 4754-2017）做重点行业的企业主体统计与结构分析，企业明细数据源为天眼查（经 `tyc` CLI 获取）。

## 目录结构

```
.
├── data/                  # 数据文件（CSV，UTF-8）
│   ├── 北京分行业法人单位数_2023五经普.csv    # 五经普口径各行业门类法人单位数，作总量基准
│   └── 北京电力供应企业名单_天眼查.csv        # 电力供应业企业明细，作重点行业下钻样本
├── docs/
│   └── tyc-cli-查询模式.md   # 天眼查 CLI 查询模式笔记（分层架构 / 命令 / 代码格式 / 配额）
└── README.md
```

## 数据口径

| 数据 | 来源 | 用途 |
|---|---|---|
| 分行业法人单位数 | 北京市第五次全国经济普查（2023 年末） | 各行业门类总量与占比基准 |
| 重点行业企业明细 | 天眼查 `tyc` CLI | 按行业代码 + 地区代码拉取企业清单，做重点行业样本 |

- 地区代码：北京市 `00110101`（`areaCode`）
- 行业代码：GB/T 4754 纯数字码，如 `44`（电力、热力生产和供应业）、`4420`（电力供应）

## 常用命令

```bash
# 环境自检
tyc --version

# 按行业 + 地区拉企业清单（示例：北京市电力供应业）
tyc company companies-by-industry-region "电力" \
  --industry "4420" --region "00110101" \
  --pageNum 1 --pageSize 50 --md
```

更多查询模式、代码格式陷阱与配额规则见 [docs/tyc-cli-查询模式.md](docs/tyc-cli-查询模式.md)。

## 数据更新约定

1. 天眼查拉取结果落盘到 `data/`，文件名格式 `{地区}{行业}_{数据源}.csv`。
2. CSV 统一 UTF-8（含 BOM 便于 Excel 直接打开），字段顺序保持不变，便于跨版本 diff。
3. 每次数据更新在提交信息中注明数据月份与拉取口径。
