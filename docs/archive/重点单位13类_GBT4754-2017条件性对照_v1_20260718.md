# 13类重点单位与《国民经济行业分类》的条件性对照

> [!IMPORTANT] 结论先行
> DB11/T 2552—2026列举的是**治安保卫重点单位类别**；GB/T 4754—2017划分的是**主要经济活动**。二者不是一一对应关系。
>
> 本表用于确定“某类重点单位通常可能采用哪些行业代码”，不能仅凭行业代码判断某单位是否属于重点单位。`重要`、`大型`、`国家重点`、`国防科技工业重要产品`、`高新技术领域`等条件，均须依据公安机关、行业主管部门、项目名录、资质证书或其他认定材料另行核验。

## 一、依据、状态与使用规则

### 1. 标准状态

- **重点单位依据**：DB11/T 2552—2026《单位内部安全防范通用要求》第6.1条。
- **发布日期**：2026年6月30日。
- **实施日期**：2026年10月1日。
- **当前状态**：截至2026年7月18日，标准已经发布、尚未实施。
- **行业分类依据**：GB/T 4754—2017《国民经济行业分类》，采用2019年第1号修改单修订后的现行文本，共20个门类、97个大类。

本地标准文件：`C:\Users\necro\OneDrive\文档\地标\DB11T 2552-2026 单位内部安全防范通用要求.pdf`

### 2. DB11/T 2552—2026的列举结构

第6.1条包含：

- a）至m）：13类明确列举的重点单位；
- n）其他需要列为治安保卫重点的单位：兜底条款。

因此，“13类”是对a—m项的简称，不是封闭范围。

### 3. 本表的三种对应关系

| 标记 | 含义 | 使用方式 |
|---|---|---|
| **直接对应** | 单位名称已经能够指向较明确的主要经济活动 | 可优先核对该代码 |
| **条件对应** | 同一重点单位类别包含多种主体或活动 | 按法人/产业活动单位的主要经济活动选择 |
| **属性条件** | GB/T 4754不能表达的安全、规模或资格条件 | 必须另查重点单位认定材料，不得由行业代码推定 |

> [!WARNING] 基本边界
> 1. 一个单位存在多种活动时，按其**主要经济活动**确定行业代码。
> 2. 单位内部的仓库、机房、实验室、配电室等辅助活动，通常不另行改变该单位行业代码。
> 3. 项目业主、场所运营方、物业管理方、入驻商户、施工承包商应分别判断，不得共用一个代码。

- 商贸中心由单一企业自营百货或超级市场时，可按`F → 52 → 5211百货零售`或`5212超级市场零售`。
- 单纯提供物业管理或房地产租赁的主体，可分别涉及`K → 70 → 7020物业管理`、`7040房地产租赁经营`。

### 边界

- 应优先编码“场所运营管理主体”，不能把商场内所有商户的零售代码等同于商贸中心代码。
- 7850是城市公园管理，不是体育主题公园；体育场馆管理应使用8921。
- `大型`须按相关认定标准、容量、面积、客流或公安机关认定另行判断。

## 13. 重要高新技术领域企业

### 核心结论

GB/T 4754—2017没有“高新技术企业”或“高新技术领域”这一独立门类。高新技术企业是资格/技术领域认定，高技术产业是以GB/T 4754为基础形成的派生分类，二者也不能完全等同。

### 常见高相关代码示例

| 技术或业务方向 | 可能代码 |
|---|---|
| 医药制造 | C27相应小类 |
| 航空航天器及设备 | C374相应小类 |
| 半导体分立器件、集成电路制造 | C3972、3973 |
| 电子元件、电子电路及电子专用材料 | C398相应小类 |
| 医疗仪器设备 | C358相应小类 |
| 仪器仪表 | C40相应小类 |
| 软件开发 | I6511—6519 |
| 集成电路设计 | I6520 |
| 信息系统集成、物联网 | I6531、6532 |
| 运行维护、信息处理存储、技术咨询 | I6540、6550、6560 |
| 研究和试验发展 | M7310—7350 |
| 专业技术服务 | M74相应小类 |
| 生物、新材料、节能、新能源、环保技术推广 | M7512—7516 |

### 推荐的双重判定

1. **行业代码**：按企业主要经济活动确定GB/T 4754代码。
2. **高新技术属性**：核验高新技术企业证书、国家重点支持的高新技术领域、主管部门名录，或《高技术产业（制造业）分类（2017）》《高技术产业（服务业）分类（2018）》等派生分类。
3. **重要属性**：再核验公安机关或行业主管部门对“重要”的认定。

### 边界

- 不能把重要高新技术企业限定为C、I、M三个门类；新能源、生态环境、现代农业等主体可能按其主要活动落入其他门类。
- 集成电路设计是6520，集成电路制造是3973，两者不可混用。

## 四、n项兜底：其他需要列为治安保卫重点的单位

DB11/T 2552—2026第6.1条n项意味着，未落入前13类的单位仍可依法或依认定列为重点单位。

因此：

- A—T任何门类理论上均可能出现依n项认定的重点单位；
- 不应再制作“未被13类触及，所以不属于重点单位”的排除清单；
- 行业代码只能辅助分组、统计和路由，不能替代重点单位认定。

## 五、实际编码决策流程

1. **确认对象**：法人单位、产业活动单位、项目业主、施工承包商、场所运营方还是内设部门。
2. **确认主要活动**：以收入、增加值、从业人员等主要活动判定资料为准。
3. **选择GB/T代码**：优先使用本表“直接对应”；跨业务单位使用“条件对应”。
4. **附加重点属性**：记录DB11/T 2552—2026第6.1条具体项次a—n。
5. **附加认定依据**：记录公安机关决定、行业主管部门名录、项目批复、资质证书等。
6. **记录重要部位**：仓库、实验室、机房、金库等是辅助活动时，不改行业代码，但应按标准第6.2条识别为重要部位或区域。

### 推荐数据字段

| 字段 | 示例 |
|---|---|
| `unit_name` | 某单位名称 |
| `gbt4754_code` | 7222 |
| `gbt4754_name` | 商业综合体管理服务 |
| `db11_category` | j |
| `db11_category_name` | 大型文化、体育场所和商贸中心 |
| `recognition_basis` | 公安机关认定文件/主管部门名录 |
| `important_qualifier` | 大型商贸中心 |
| `notes` | 运营主体；商户另行编码 |
