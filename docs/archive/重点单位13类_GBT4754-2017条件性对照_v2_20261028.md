# 13类重点单位与《国民经济行业分类》的条件性对照（第二版）

> [!IMPORTANT] 结论先行
> DB11/T 2552—2026 第6.1条列举的是**治安保卫重点单位类别**；GB/T 4754—2017 划分的是**主要经济活动**。二者不是一一对应关系。
>
> 本表是**条件性对照**，用于候选单位检索、行业归类和统计分组。所列行业代码为常见对应或条件对应，**不构成穷尽清单**：代码相同的单位不当然具有相同的重点单位身份，未列入本表的代码也不据此排除重点单位。
>
> 行业代码、业务或资格属性、重点单位确定依据三者**分别记录、不得相互替代**。第6.1条各项中的"重要""大型""国家重点""国防科技工业重要产品""高新技术领域"等条件，均须依据公安机关的确定文件、主管部门名录、项目批复、资质证书等材料另行核验。

## 一、依据、状态与使用规则

### 1. 标准与分类依据状态

- **重点单位依据**：DB11/T 2552—2026《单位内部安全防范通用要求》第6.1条。
- **发布日期**：2026年6月30日（北京市市场监督管理局2026年标字第11号公告，目录第15项）。
- **实施日期**：2026年10月1日。**截至2026年10月28日，标准已实施**（第一版"尚未实施"为2026年7月的时点描述，此处更新）。
- **现行文本入口**：国家标准信息公共服务平台标准详情页及北京市标准信息服务平台在线文本入口，见文末[S1]；引用时以正式发布PDF第6.1条为准，不以征求意见稿替代。
- **行业分类依据**：GB/T 4754—2017《国民经济行业分类》，采用2019年第1号修改单修订后的现行文本，共20个门类、97个大类；代码名称与包含/排除注释以国家统计局《2017国民经济行业分类注释》为准。

### 2. 第6.1条的列举结构

第6.1条包含：

- **a）至m）**：13类明确列举的重点单位；
- **n）**：其他需要列为治安保卫重点的单位（兜底条款）。

"13类"是a—m项的简称，不是封闭范围。地标采用的是混合分类：a项主要按主体性质，b/e/f/i项主要按业务或行业，d/g/j项含设施和场所，c/h/k项含产品、物资或风险属性，l项按项目地位，m项按技术领域与重要性。该分类服务于安全管理，**不具备行业分类的互斥结构**，因此不能按"一类对应几个门类代码"的方式整段纳入。

### 3. 四层对应关系（第一版"三种关系"的修订）

第一版把"直接对应／条件对应／属性条件"并列为三种关系。前两者描述**映射强弱**，第三者描述**资格条件**，维度不同；且"直接对应"易被误读为整类纳入。第二版改为两层映射＋两项限定：

| 层次 | 标记 | 含义 | 使用方式 |
|---|---|---|---|
| 映射 | **常见对应** | 该类别的主要活动与代码的对应关系稳定 | 可优先检索；仍须核验单位身份与第6.1条各项条件 |
| 映射 | **条件对应** | 同一类别含多种主体或活动，代码是否适用取决于实际业务 | 按统计对象的主要经济活动逐户判断 |
| 限定 | **行业内需限定的范围** | 代码正确，但该小类下只有部分单位属于本项对象 | 在小类内部按产品、业务、环节再筛 |
| 限定 | **资格或属性条件** | GB/T 4754 无法表达的安全、规模、等级或资格条件 | 另查确定依据与属性证明，不得由代码推定 |

> [!WARNING] 基本边界
> 1. 一个单位存在多种活动时，按**主要经济活动**确定行业代码（判定顺序见第五部分第1条）。
> 2. 单位内部的仓库、机房、实验室、配电室、金库等辅助活动，通常不另行改变该单位行业代码；但可能使该单位符合某项重点单位条件（另见第5条）。
> 3. 项目业主、场所运营方、物业管理方、入驻商户、施工承包商应分别判断，不得共用一个代码。
> 4. **一个统计对象可以同时对应多个项次**（如科研院所兼涉国防与菌毒种、博物场馆兼涉g/j项）；按类别展示时可重复，计算总数时按统计对象去重，不得直接累加13类数量。

### 4. 认定依据分两层（第一版的主要缺陷之一）

第一版把公安机关决定、主管部门名录、项目批复、资质证书混列在同一"认定依据"栏。应分层记录：

| 层次 | 内容 | 作用 |
|---|---|---|
| **重点单位确定依据** | 依《企业事业单位内部治安保卫条例》（国务院令第421号）第十三条，公安机关提出、报本级人民政府确定的文件；其他类别依其适用制度确定的文件 | 决定"是否为重点单位" |
| **业务及属性证明** | 主管部门名录、业务许可、项目批复或核准、高新技术企业证书、文物保护等级、储备任务文件、危险物品许可等 | 证明"属于哪一类、具备何种属性" |

除另有明确依据外，业务及属性证明**不单独替代**重点单位确定程序。对党政机关等主体，应核对其适用的具体制度依据，不宜把企业事业单位条例中的程序机械外推。

### 5. 多类交叉与计数规则

- 类别字段应可多值（`db11_category` 允许多项），每项单独记录对应对象与活动。
- 计算重点单位总数时，按统一统计对象标识去重。
- 法人、分支机构、产业活动单位、场所、建设项目不得混为同一计数单位。
- 如需互斥分类，应另行确定主类别分配规则，不以本表列举顺序自动分配。

## 三、逐类行业代码对照

### 1. 党政机关、社会团体（a项）

**判断**：S门类是主要对应，但不能覆盖全部；不能把 S95 各类社会组织都等同于"社会团体"。

**常见对应**

| 对象 | 门类 → 大类 → 中类/小类 |
|---|---|
| 中国共产党机关 | **S → 91 → 9100 中国共产党机关** |
| 国家权力机构 | **S → 92 → 9210 国家权力机构** |
| 国家行政机构 | **S → 92 → 922**：9221 综合事务管理、9222 对外事务管理、9223 公共安全管理、9224 社会事务管理、9225 经济事务管理、9226 行政监督检查 |
| 监察委员会、人民法院、人民检察院 | **S → 92 → 923**：9231 监察委员会、9232 人民法院、9233 人民检察院 |
| 其他国家机构 | **S → 92 → 929**：9291 消防管理机构、9299 其他未列明国家机构 |
| 人民政协、民主党派 | **S → 93**：9310 人民政协、9320 民主党派 |
| 社会团体 | **S → 95 → 952**：9521 专业性团体、9522 行业性团体、9529 其他社会团体 |

**条件对应**

| 对象 | 代码 | 限定条件 |
|---|---|---|
| 群众团体 | 9511 工会、9512 妇联、9513 共青团、9519 其他群众团体 | 是否按a项管理应标明所依据的管理口径；9519 注释含宋庆龄基金会、国家自然科学基金会等，名称含"基金会"的主体未必落9530 |
| 基金会 | 9530 基金会 | 属社会组织，但不因属"社会组织"便当然成为a项中的"社会团体" |
| 宗教团体 | 9541 宗教团体服务 | 仅指在民政部门登记的宗教团体 |
| 宗教活动场所 | 9542 宗教活动场所服务 | 是场所活动，不能与9541互换；受文物保护的教堂、寺庙管理另按8840核对 |

**行业内需限定的范围**

- 国家统计局注释明确：部分社会团体从事有偿服务时，按实际服务行业归类；红十字会、部分慈善活动可涉及 **8529 其他不提供住宿社会工作**。具有社会团体身份的单位，不必然只落在952。
- 金融监管活动在GB/T 4754中有专门代码（6650 银行监管服务、6750 证券期货监管服务、6870 保险监管服务）。对符合相关机关身份的监管主体，不能因组织性质强行改入S92。

**边界**

- `94 社会保障`、`96 基层群众自治组织`不应仅因同属S门类而自动纳入。
- 居委会、村委会只有经第6.1条n项或其他依据确定为重点单位时，才进入重点单位范围。

### 2. 广播电台、电视台、通讯社、报社等重要新闻单位（b项）

**判断**：主要对应准确，保留为主；需区分内容生产与信号传输。

**常见对应**

| 对象 | 代码 |
|---|---|
| 通讯社、新闻机构 | **R → 86 → 8610 新闻业** |
| 报社 | **R → 86 → 8622 报纸出版** |
| 广播电台 | **R → 87 → 8710 广播** |
| 电视台 | **R → 87 → 8720 电视** |

**条件对应**

| 对象 | 代码 | 限定条件 |
|---|---|---|
| 广播电视集成播控机构 | 8740 广播电视集成播控 | 限符合"重要新闻单位"口径的集成播控主体，不能仅由播控活动推定新闻单位身份 |
| 期刊社 | 8623 期刊出版 | 须核实是否实际从事新闻业务；一般期刊不整类纳入 |
| 数字新闻出版主体 | 8626 数字出版 | 同上；一般数字出版不整类纳入 |
| 互联网新闻信息服务主体 | 6429 互联网其他信息服务 | 须核实是否从事新闻信息采编发布 |

**行业内需限定的范围**

- **内容生产、新闻发布**通常落在 R86／R87；**信号传输**通常落在 I632（6321 有线、6322 无线广播电视传输服务）、I633（6331 广播电视卫星传输、6339 其他卫星传输），后者应核对第9类i项，**不得按"广电"名称统一编码**。

**边界**

- 8621 图书出版、8730 影视节目制作、8750 电影和广播电视节目发行、8760 电影放映、8770 录音制作，不因同属86或87大类而自动成为"重要新闻单位"。
- "重要"须通过新闻主管部门材料或重点单位确定文件核验。

**判断**：按活动环节拆分的方法正确；制造活动示例不完整，检测范围需收窄。

**常见活动及代码示例**

| 活动环节 | 代码 | 说明 |
|---|---|---|
| 自然科学研究 | **M → 73 → 7310 自然科学研究和试验发展** | 按实际科研任务核验 |
| 工程技术研究 | **M → 73 → 7320 工程和技术研究和试验发展** | 同上 |

| 仪器仪表制造 | **C → 40**，按实际产品选择 | 同上 |
| 专用装备制造 | **C → 35**，按实际产品选择 | 同上 |
| 独立检测、试验服务 | **M → 74 → 7452 检测服务** | 独立检测主体 |

**条件对应（须以实际产品、国防任务和本项适用依据核验，不能整类认作军工）**

| 代码 | 限定条件 |
|---|---|
| 2530 核燃料加工 | 涉核燃料、核材料任务 |
| 2671 炸药及火工产品制造 | 注释含军用炸药与火工产品 |

**行业内需限定的范围**

- C35／C39／C40 是检索范围，不是纳入结论；具体单位必须落实到实际小类，并证明其产品属于国防科技工业重要产品。
- 7452 以外的质检活动（7454、7455、7459）并不天然等同于试验活动。

**边界**

- GB/T 4754 不以"军品""涉密""国防重要产品"作为行业代码维度，须在实际代码之外叠加国防任务、资质或确定依据。
- **"涉密属性"是可能的辅助证明**，不宜与国防属性、产品重要性并列写成每个对象都必须满足的共同条件；第6.1条c项未单列"涉密"门槛。
- 376 是自行车和残疾人座车制造，3770 是助动车制造，均非航空航天或武器弹药制造。
- 单位内部试验室、库房属辅助活动时，不另改主行业代码。

## 五、编码决策流程与数据记录要求

### 1. 决策流程

1. **确认统计对象**：法人单位、产业活动单位、项目业主、施工承包商、场所运营方，还是内设部门/场所。场所与法人分别标识。
2. **确认主要活动**：原则上按**增加值份额**最大的活动确定；不能据此确定的，再依据销售收入、营业收入或从业人员等资料确定，并留存判定依据。不得以单位名称、经营范围关键词、主管部门或所参与项目替代主要活动判定。
3. **选择GB/T代码**：优先核对"常见对应"，跨业务单位用"条件对应"，并在小类内部按"行业内需限定的范围"再筛。
4. **标注地标项次**：记录第6.1条具体项次 a—n，**允许多值**，每项记明对应对象与活动。
5. **记录确定依据**：与业务/属性证明**分栏填写**（见第一部分第4条）。
6. **记录重要部位**：仓库、实验室、机房、金库等属辅助活动时，不改行业代码，但应按标准第6.2条识别为重要部位或区域。
7. **标记交叉与去重键**：标记同时符合多项的单位，设置统一去重标识。
8. **标注确定状态**：候选／待核实／已核实，避免把候选数表述为重点单位数。
